Apache Maka（Incubating）

项目概述：Apache 孵化中的本地优先 AI Agent 工作台，以 Runtime Event Log 统一记录模型、工具、权限与终止事件。

重要 PR

  • #3028 Work Board 核心契约与存储 Core / SQLite Store、revision CAS、游标分页、事务串行化。
  • #3135 Work Board Desktop MVP 主进程存储权威、IPC 投影与完整事项操作。
  • #3165 Session Catalog 协议与存储重构 清理无效过滤与冗余表，完成 schema v26 迁移及兼容性升级。
  • #567 / #956 Task Ledger 演进 持久生命周期事件、层级任务与子 Agent 关联。
  • #3751 Runtime 异常恢复 限制 malformed compaction 重试并传递可操作的恢复信息。

重要 Issue

  • #559 Durable Task Lifecycle RFC 提出持久任务生命周期与证据模型。
  • #883 层级任务与子 Agent 协作 提出任务层级、协作关联和可视化方案。
  • #3726 外部条件驱动的 Session Follow-up 讨论外部事件触发、幂等续接与权限边界。
  • #3743 异常压缩摘要导致 Session 阻塞 完成问题定位并通过 PR #3751 推进修复。

OpenPI

项目概述：基于 Pi 的 Agent 开发配置项目，通过工作流和扩展机制组织子任务、会话事件与开发工具。

重要贡献

  • PR #146 Workflow 响应完整性修复 要求子任务产生 assistant settlement 后才能返回成功，避免空输出被误判为成功。
  • Issue #115 Schema-less Workflow 空响应 围绕该问题完成复现、生命周期边界分析与测试闭环。

技术总结

  • Agent Runtime：状态机、事件生命周期、Checkpoint 恢复、重试边界与错误传播。
  • 本地优先架构：主进程存储权威、IPC 投影、SQLite 事务、CAS 并发控制与游标分页。
  • 协议与迁移：跨层契约演进、兼容性 epoch、数据库 schema 迁移与旧能力收敛。
  • 工程质量：从 Issue 复现和边界分析，到实现、回归测试与 PR 评审闭环。
